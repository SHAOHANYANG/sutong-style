## 类别规则（与67条例子同等有效）

本表只是“什么叫书面语”的示例，**不是**只改表内词的穷举名单。原文中未列出的同类表达也必须改写：

- 任何四字成语、四字格或固定书面短语，都拆成普通人会说的完整大白话；`莫名其妙`、`小心翼翼`、`不可思议`是明确口语常用例外。人名、地名、称谓不属于这一规则。
- 任何文言虚词或书面连接词，如“之、其、乃、遂、颇、甚、矣”，按意思替换成口语或直接删除。
- 任何书面单字动词或凝练动作词，如“凝视、伫立、颔首、蹙眉、噙、沁”，换成日常说法。
- 任何生僻颜色、光感或质感词，换成常见说法，同时保留颜色、程度、位置和质感这一事实。
- “仿佛、犹如、宛若”等书面比拟词一律改为“好像”“像”或完整日常比喻。
- “哭/泣”相关表达必须按上下文在“哭了、掉眼泪、哭得说不出话、满脸是泪”等自然说法之间轮换；不得把不同的哭法一律压成同一个词，也不得丢掉哭泣强度、是否出声等事实。

## 必须保留（内容，不保留原文文体）

- 人名、地名、职官/宫廷称号必须原样保留。普通家庭称谓不自动硬保护，但带序数的称谓（如大少爷、大太太、二/三/四太太、二/三/四姨太）必须原样保留。
